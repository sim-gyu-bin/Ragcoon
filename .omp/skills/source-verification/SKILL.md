# 공식 근거 확인

1. 확인할 질문 하나와 적용 버전·환경을 특정한다. 의존성 선언 범위와 실제 설치·잠금 버전을 혼동하지 않는다. 아직 버전을 정하지 않았다면 그렇게 표시한다.
2. 같은 버전·조건에서 이미 확인한 근거가 있으면 재사용한다. 아니면 공식 버전 문서, 릴리스 노트, 해당 태그의 소스부터 찾는다. 검색 요약이나 최신 예제를 구버전 지원의 증거로 삼지 않는다.
3. 질문에 맞는 경계를 확인한다. 예를 들어 LangGraph 스트리밍은 실제 이벤트 형식, Chroma는 데이터가 지속되는 경로, LangSmith는 추적에 포함되는 필드, OCI는 이미지의 ARM64 지원과 계정의 과금 조건을 구분해 본다.
4. 실행 확인이 필요하면 [핵심 규칙](../../RULES.md) 안에서 해당 경로만 검증한다. 자료 조회 요청을 유료 호출·설치·배포 승인으로 해석하지 않는다.
5. 결론에는 공식 URL, 적용 버전·환경, 문서에서 확인한 사실, 실제 관찰 결과 또는 미실행 조건을 남긴다. 반복해서 쓸 결정만 [학습 Wiki](../llm-wiki/SKILL.md)로 정리한다.
