# 학습 Wiki

**Query — 질문에 답할 때.** `docs/wiki/`에 관련 주제가 있으면 그 문서부터 읽고, 구현 설명은 현재 파일과 심볼을 대조한다. Wiki가 없으면 코드·기존 문서로 바로 답한다. 설계 제안과 실제 구현을 구분하며, 조회만으로 파일을 만들지 않는다.

**Ingest — 다시 쓸 지식을 남길 때.** 문서 수정이 요청 범위에 있고 다음 기능에서도 참고할 결정이나 검증 결과가 있을 때만 기록한다. 예를 들어 검색 근거와 생성 답변을 별도로 평가하기로 했다면 이유와 재현 방법을 남긴다. 기존 주제를 먼저 갱신하고 새 주제에 실질적인 내용이 있을 때만 `docs/wiki/<주제>.md`를 만든다. 본문은 ‘질문 → 현재 결론과 이유 → 근거(경로·심볼 또는 공식 URL) → 확인 방법·미확인 조건’이면 충분하다. 대화 원문·업로드 데이터·일일 작업 이력은 기록하지 않는다.

**Lint — 지식이 맞는지 확인할 때.** 요청한 주제 또는 발견한 불일치만 대상으로 링크·심볼·버전과 구현 상태를 확인한다. 차이가 있으면 ‘문서 주장 / 실제 근거 / 수정 제안’으로 설명한다. 실행하지 않은 내용을 검증됐다고 쓰거나 승인된 설계를 현재 코드에 맞춰 임의로 바꾸지 않는다.
